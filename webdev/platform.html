Get Started in 4 Simple Steps

Set up NeuraShield AI security scanning for your repository in under 5 minutes

1

Add OpenAI API Key to GitHub Secrets

Navigate to your repository settings and add your OpenAI API key as a secret

  • Go to your GitHub repository
  • Click Settings → Secrets and variables → Actions
  • Click "New repository secret"
  • Name: OPENAI_API_KEY
  • Value: [Your OpenAI API Key]
  • Click "Add secret"
2

Copy Workflow Configuration

Create the neurashield.yml workflow file in your repository

.github/workflows/neurashield.yml 
name: NeuraShield Security Scan

            on:
            pull_request:
                types: [opened, synchronize, reopened]
                paths:
                - '**.py'
            workflow_dispatch:

            permissions:
            contents: read
            pull-requests: write
            issues: write

            jobs:
            security-scan:
                uses: AaryaSoni-web/neurashield-ai/.github/workflows/reusable-analysis.yml@main
                with:
                source-repo: ${{ github.repository }}
                pr-number: ${{ github.event.pull_request.number }}
                secrets:
                OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
3

Create a Pull Request & Get Report

Make any code change and create a PR to trigger the security analysis

  • Create a new branch in your repository
  • Make changes to Python files (*.py)
  • Commit and push your changes
  • Create a Pull Request
  • Get automated security report as PR comment

4

Receive Email Notification from GitHub

GitHub automatically sends email notifications when the workflow completes

  • Check your email inbox (associated with GitHub account)
  • Look for notification from GitHub Actions
  • Email contains link to workflow run
  • Click to view full analysis report
